Front-page experiments

Five takes on a living background, each one full-bleed behind the same placeholder copy so you can judge legibility, not just the effect. No dependencies, no build step.

Delaunay / Voronoi

canvas 2d ↗

Sites drift on a Perlin flow field; the triangulation is rebuilt every frame with Bowyer–Watson and the Voronoi cells come off its dual. The cursor shoves sites away and makes nearby cells pull back from their own edges, so the plane looks like it is shattering around you.

move — shatter + repel · scroll — 18…420 cells

Mandelbrot / Julia

webgl ↗

A fragment shader with continuous escape-time colouring, zooming forever into seahorse valley. The cursor steers the descent — it aims at whatever is under the pointer. Click to flip to Julia, where the cursor rides the main cardioid's boundary and the set morphs live.

move — steer / set c · scroll — zoom · click — switch set

Game of Life

canvas 2d ↗

B3/S23 on a torus, drawn as crisp squares on the device pixel grid — no blur, no upscaling. Life only reads as Life if you can pick out a glider and watch it walk, so the subtlety is in the colour being pale, not in the cells being vague. Dying cells leave a one-generation ghost.

Life on a finite grid does stop. Churn is measured every step and the field is fed a soup only once it has genuinely settled — never while the pattern is still doing something on its own.

move — seed · click — drop a soup · scroll — 1…60 gen/s

ASCII donut

text ↗

Andy Sloane's donut, kept as he wrote it — a torus swept as two nested angles, spun about x and z, projected with 1/z and resolved by a z-buffer. Each surface normal is dotted with a light behind the viewer and that luminance indexes twelve glyphs from . to @. The shading is the character set; no colour does any work. Output is a <pre>, so it stays real selectable text rather than pixels.

move — lean it toward the cursor · scroll — glyph size

tunable: ?fs=, ?fill=

Tesseract

text ↗

The 4-cube, wireframed in the same glyph ramp — sixteen vertices at every (±1,±1,±1,±1), and an edge wherever two differ in exactly one coordinate. Rotation in 4-space happens in a plane, not about an axis, so there are six to choose from and no axis of rotation exists.

Two perspective divides, not one: 4D→3D through w, then 3D→2D through z. That first divide is the whole trick — there is no small inner cube in the object, only the far cell in w being shrunk, which is why the two swap places as it turns. Depth drives the glyph, so the brightness you read is mostly the fourth dimension.

move — turn it in two planes · scroll — glyph size

tunable: ?fs=, ?fill=, ?offset=

All three honour prefers-reduced-motion by holding still. The fractal is capped at a zoom of about 4×10⁵ — past that, 32-bit floats in the shader run out of mantissa and the image breaks into blocks, so it breathes back out instead. The automaton's rule is URL-tunable (n, r, t, cell, warm): high thresholds relative to the neighbourhood size never nucleate and stay as noise indefinitely.

Each page sets --bg-strength to hold the background back behind the copy; raise it per page if any of these want more presence. Sloane's angular steps assume a donut about 30 characters across, so the donut scales them with its projected size — sample that surface onto a 250-column grid at the original steps and the samples stop touching, which reads as stripes instead of a skin. There is a fourth on disk — a cyclic automaton, spiral waves that never settle — left in as an aside.
